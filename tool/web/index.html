SETUP GUIDE

先安装功能，再自由导入。

区分机身固件安装与 SD 配方导入，避免把复制完成误认为刷机完成。

纯原厂 ILCE-7M3 4.04 · 实验候选

只接受匹配的纯原厂机。已安装项目功能的相机会在前像检查时停止。当前相机与 Windows USB 实物链路尚未验收，可能出现无法启动；已有备份也不保证可恢复。请勿把这个实验候选作为稳定版分发。

操作顺序：选专用候选包 → 读取并备份 → 核对结果 → 单独确认写入 → 断电验收。普通 v0.01 ZIP 不适用于此入口。

未连接相机。启动工具不会自动扫描或切换 USB。

Windows 需要两个 USB 模式的兼容驱动。Mac 当前只支持已通过 UTM 交回 Mac 的服务模式设备。保存写入时不要退出工具；发生错误会停止，不自动重试。

机内已有「从 SD 卡导入」

  1. 相机设为「大容量存储」，用 Micro-USB 接电脑；Mac 暂不分配给 UTM。
  2. 在「配方与 SD 卡」选卡根目录、选配方，点击「复制所选到 SD 卡」，等回读完成。
  3. Windows 在资源管理器、Mac 在 Finder、Linux 在文件管理器中安全推出。等存取灯熄灭后拔 USB。
  4. MENU → 拍摄设置 1 → 第 14 页 → 同级「从 SD 卡导入」。左右选文件，确认导入，等「完成」。
  5. 进入「创意外观」，选择新增风格；调整后保存 → 确认。拍 JPEG 并回放，重启检查保留。

卡根目录最多列 32 份配方；机内最多 16 个自定义外观（满额实机尚未逐项验证）。重复 ID 不能直接覆盖；需要时从机内删除旧自定义项后重新导入。

找不到卡 / 连接失败

先确认电脑能在文件管理器里打开 SD 卡。如果已把 USB 分配给 UTM，请先释放，再按需重新插线。只有 USB 设备名、没有存储卷时，本工具无法复制文件。

不要选择 PMHOME 或电脑系统盘。选择包含 DCIM 的存储卡根目录；扫描不到时可手动填路径。GUI 不会自动改 USB 驱动或接管虚拟机。
