# 六套创作配方

基于现有 FL 配色和机内调节项设计，不是新 LUT 或品牌官方配方。已通过 Python 格式校验及与机内同源 C 解析器校验，尚未做六套实拍验收。实际效果会随场景、曝光和白平衡变化。

| 名称 | 基础 | 设计取向 |
|---|---|---|
| 暖调人像 | FL6 | 温和色彩、轻抬黑位、压低高光，颗粒 1 |
| 冷调街拍 | FL5 | 冷阴影、较高反差和轻暗角，颗粒 2 |
| 褪色负片 | FL4 | 抬黑、低饱和、明显褪色，颗粒 3 |
| 浓郁电影 | FL3 | 深阴影、浓色、轻光晕和暗角，颗粒 2 |
| 柔和日系 | FL6 | 明亮中间调、低反差及低饱和，关闭三项拍后效果 |
| 暖调纪实 | FL4 | 暖亮部、适度反差、轻暗角，颗粒 2 |

复制 `.a7look` 至 SD 根目录，在同级「从 SD 卡导入」选择文件并确认，然后在「创意外观」中选中、保存。每套 ID 独立；不要反复导入同一 ID。颗粒、光晕和暗角作用于拍后 JPEG，可能增加保存时间；柔和日系关闭这些效果，可先用它快速比较。机内最多 16 个自定义项。
