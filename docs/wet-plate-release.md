# Sony A7M3 v0.01 完整整合包 · FL7 湿版黑白

本包整合 FL～FL7、独立参数、五点曲线、JPEG L/M/S 拍后颗粒／正负光晕／正负暗角、SD 导入、删除、动态名称和即时列表。新增独立「FL7 湿版黑白」，以及原有风格各自的「湿版黑白（拍后）」开关。继续使用 v0.01 和同名完整 ZIP，不单独发布 r 版本。

## 机内使用

MENU → 拍摄设置 1 → 第 14 页 →「创意外观」。

- **直接拍黑白：** 选择 FL7 湿版黑白，到第 4 页「保存 → 确认」，看到完成后拍 JPEG。FL7 的黑白固定开启。
- **给已有风格加黑白：** 选一个原有或导入的风格，第 3 页末尾「湿版黑白（拍后）」设为开，保存→确认。关闭再保存即可恢复该风格的彩色直出。各风格独立保存，首次升级默认关。
- **取景：** 可以保持彩色，黑白在拍摄后、JPEG 编码前处理。此开关不修改 RAW。
- **删除：** 选中风格，第 5 页「删除」，确认或取消。原 FL～FL6、自定义风格和 FL7 都可删除；FL7 删除后不会每次开机重新出现。
- **SD 导入：** 配方放在卡根目录，从与创意外观同级的「从 SD 卡导入」选择 `.a7look`，核对文件名并确认。导入完成后立即出现在列表，可连续切换，最终选中状态及参数仍需保存。

当前已实测全画幅 3:2 JPEG L（6000×4000）、M（3936×2624）、S（3008×2000）。每张等待存取灯熄灭再拍下一张；多种拍后效果叠加会延长保存时间。RAW、实时黑白、APS-C、16:9、视频和连拍不在本轮验证范围。

## 保留和兼容性

升级保留现有六套配色、各项参数、独立导入库及原有删除状态；不复活已经删掉的风格。FL7 在首次启动追加为独立风格，占一个自定义名额，上限仍为 16。空间满时安装迁移会拒绝，须先备份并腾出风格名额，不擅自删除用户配方。

原六套 A7FL 配置仍是 schema 6。A7CU 独立库会升级为同长度的 schema 3，记录黑白开关和一次性 FL7 追加状态；兼容读取旧 schema 1/2。旧模块不能直接读取 schema 3，回退须使用匹配的安装前配置备份。

`.a7look` 仍使用 `A7FL-LOOK/1`，包含 ID、名称、基础 FL 和原有 16 项参数；文件名随意，内容必须合法。当前文件格式尚未增加黑白开关字段，导入后在机内开启并保存。配方不携带任意算法或 LUT。`recipes/defaults/` 是六套零调节基础配方（锐度范围 3），不是机主个人参数。

## 包内内容和校验

- `a7fl.so`：已写入并完整回读的整合模块，内嵌本次实拍通过的黑白处理内核。
- `locales/`：从六风格版语言资源生成当前资源的累计中英文增量补丁；`locales/from-previous/`：从上一个 SD 导入／删除版资源升级的增量补丁。
- `tools/apply_release_locales.py`：离线资源生成器；`source/`：清单所指提交的完整源码与开发、分阶段部署工具。
- `recipes/`、`docs/`：公开配方、使用和构建说明、六风格模拟色卡。色卡不代表 FL7 实拍。
- `release-manifest.json`、`SHA256SUMS`：源码提交、版本、验证范围和文件散列。

解压后在 `Sony_A7M3-v0.01` 目录执行 `shasum -a 256 -c SHA256SUMS`。Windows 可用配方 GUI 的完整包校验功能；当前附件内旧 GUI 只处理原 16 项配方参数，不编辑新增黑白开关。

从**上一个 SD 导入／删除版**的精确语言资源生成新文件：

```sh
python3 tools/apply_release_locales.py \
  --baseline-dir /absolute/path/to/previous-custom-locales \
  --patch-dir locales/from-previous \
  --output-dir /absolute/path/to/wet-locales
```

更早六风格资源使用默认的 `locales` 补丁目录。工具验证输入散列后只生成本地文件，不连接或刷写相机。

这是完整功能包，不是 Sony 官方签名 DAT、原厂 4.04 一键首次安装器或 A7C 固件。不能只复制 `a7fl.so` 到 SD 卡升级。需要已经配置的项目加载器、匹配语言及逐机备份；本次验收的旧模块 SHA-256 为 `30474345352eaed6b1feb8f33e389278febaeb6c3fc493dc2355ab560ca591a4`。

现有开发环境使用 `source/deploy_wet_plate.py`：依据本机前像和测试证据绑定，先备份，按简中、英文、模块顺序写入，再完整回读和冷启动验收。仅替换模块不足以加入新菜单文字。脚本不是下载后直接用于任意相机的通用安装器；旧版本须先检查前像，不能删除保护条件硬刷。原厂首次安装源码仍属实验开发，未完成原厂机实测；本包不包含实验首装载荷或认证材料。

安装工具和 USB/UTM 环境见 `docs/updater.md`；本次构建流程见 `docs/wet-plate-jpeg.md`。完整 ZIP 不包含机主照片、配置、分区备份、虚拟机、原厂整包或私有安装事务。
