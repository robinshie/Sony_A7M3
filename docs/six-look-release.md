# Sony A7M3 v0.01 六风格整合版

这是一个包含当前全部创意外观功能的包。FL、FL2、FL3（徕卡胶片）、FL4（经典负片）、FL5（经典纪实）、FL6（自然人像）各有独立参数、五点曲线、拍后颗粒、正负光晕和正负暗角。保留保存→确认／取消→完成，以及取景刷新流程。新增三套配色是近似创作，不承诺复刻原厂品牌配色。

2026-11-15 已在本项目 A7M3 4.04 开发机写入、完整回读并完成用户冷启动验收：六个入口、FL4／FL5／FL6 拍摄回放、独立参数保存及重启保留正常。后续只读回查确认驻留正常、模块无错误、schema 6 设置有效、拍后内核诊断模式为 0。用户结束验收后切回 FL 并作了未保存修改，因此运行状态和最后保存的 FL4 不同；该操作已由用户确认。

## 包含什么

- `a7fl.so`：六风格整合模块，包含原有拍后内核。
- `locales/`：中英文菜单增量补丁，包含新增 FL4／5／6 名称。
- `tools/apply_release_locales.py`：在本机生成完整菜单资源，不连接或写入相机。
- `source/`：与发布提交一致的完整项目源码，包括构建、UTM、检查和升级工具。
- `docs/`：原厂与整合版比较、依赖、更新流程和已有验证范围。
- `release-manifest.json` 和 `SHA256SUMS`：版本及完整性校验。

公开名称统一为 v0.01。内部安装事务号用于保留唯一的备份与日志，不单独发布 r 版本。

## 安装条件与使用

适用升级起点是已经配置本项目加载器的 r16 实验机：旧模块 SHA-256 为 `9fcaf13e5bcc5914d5721d797f16c3b059dc6f9b0cb99c94eda7632176306fe8`。当前开发机已安装六风格版，不要重复刷同一个事务。

包内不含原厂固件、用户设置或相机备份；它不是原厂 4.04 通用直装包，也不是 Sony 签名 DAT。源码中的部署工具依赖本地已验证的原厂资源、备份及基线证据，不能在另一台原厂相机上直接运行。具体依赖见 `docs/updater.md`；六风格更新路径见 `source/deploy_six_looks.py`。

先在解压目录执行：

```sh
shasum -a 256 -c SHA256SUMS
python3 tools/apply_release_locales.py \
  --baseline-dir /absolute/path/to/r16-locales \
  --output-dir /absolute/path/to/new-six-look-locales
```

生成器检查旧文件散列，输出目录必须不存在。相机安装还需在绑定当前机身前像的升级流程中依次安装简中、英文、模块，并完整回读；生成本地文件不等于完成烧录。已有 FL1–FL3 设置升级时保持，首次保存迁移到六组 schema 6；回退须配套升级前设置备份。

机内路径：MENU → 拍摄设置 1 → 第 14 页 → 创意外观。选风格、调参数、保存→确认，返回即可试拍。颗粒、光晕、暗角用于拍后 JPEG；已验证的几何为全画幅、3:2、JPEG L（6000×4000），不处理 RAW 或实时取景，每张保存完再拍下一张。组合效果未重新实拍计时。锐度、锐度范围、清晰度仍只确认可调和保存；五点曲线各控制的视觉效果仍需独立比较。
