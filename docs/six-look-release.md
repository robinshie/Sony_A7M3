# Sony A7M3 v0.01 六风格整合版 · JPEG L／M／S

这是一个包含当前全部创意外观功能的包。FL、FL2、FL3（徕卡胶片）、FL4（经典负片）、FL5（经典纪实）、FL6（自然人像）各有独立参数、五点曲线、拍后颗粒、正负光晕和正负暗角。保留保存→确认／取消→完成，以及取景刷新流程。新增三套配色是近似创作，不承诺复刻原厂品牌配色。

2026-11-15 已在本项目 A7M3 4.04 开发机写入、完整回读并完成冷启动验收：六个入口正常，M／S 拍摄回放正常。本次开机回读为处理成功 5 次、失败 0 次，颗粒、光晕、暗角的运行值与保存值一致。写入前，同一内核已通过 L／M／S 三张实拍及 JPEG 像素对照。

## 包含什么

- `a7fl.so`：六风格整合模块，内置支持自动识别 L／M／S 的拍后内核。
- `locales/`：中英文菜单增量补丁，包含新增 FL4／5／6 名称。
- `tools/apply_release_locales.py`：在本机生成完整菜单资源，不连接或写入相机。
- `source/`：与发布提交一致的完整项目源码，包括构建、UTM、检查和升级工具。
- `docs/`：原厂与整合版比较、依赖、更新流程和已有验证范围。
- `release-manifest.json` 和 `SHA256SUMS`：版本及完整性校验。

公开名称统一为 v0.01。内部安装事务号用于保留唯一的备份与日志，不单独发布 r 版本。

## 安装条件与使用

真机已验收的升级起点是已配置本项目加载器、六风格中英文资源和 schema 6 设置的上一版六风格模块，SHA-256 为 `5fb33e6955b81e02144463e6fb7e09aaa042b3e4df536fd9523854a91d2fa6d5`。该路径只更新模块，沿用两种语言资源和六套设置；对应源码工具为 `source/deploy_auto_size.py`。

源码中的部署工具依赖本机已验证的原厂资源、备份及机身前像证据。包内不含原厂固件、用户设置或相机备份；原厂 4.04 直装和从三风格版直接写入此模块均未验收。仍使用三风格版的机身应先沿上一版已验证路径安装六风格版并保存配置，完成 schema 6 迁移。

在解压目录校验所有文件：

```sh
shasum -a 256 -c SHA256SUMS
```

已安装匹配的六风格语言资源时，跳过语言补丁。需要从配套三风格前像重建菜单资源时，再执行：

```sh
python3 tools/apply_release_locales.py \
  --baseline-dir /absolute/path/to/r16-locales \
  --output-dir /absolute/path/to/new-six-look-locales
```

生成器检查旧文件散列，输出目录必须不存在；它只生成本地文件。当前开发机已安装通过验收，不重复执行同一个升级事务。

机内路径：MENU → 拍摄设置 1 → 第 14 页 → 创意外观。选风格、调参数、保存→确认，返回即可试拍。全画幅 3:2 JPEG 已验证 L（6000×4000）、M（3936×2624）、S（3008×2000）。三种效果在拍后应用，请等当张保存结束再拍下一张。组合强度 9／+9／−9 时，本次实拍处理约用 40／26／20 秒，详见 [尺寸适配记录](docs/jpeg-size-adaptation.md)。RAW、实时取景、APS-C 和 16:9 不在本次验收范围。锐度、锐度范围、清晰度仍只确认可调和保存；五点曲线各控制的视觉效果仍需独立比较。
