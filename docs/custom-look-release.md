# Sony A7M3 v0.01 完整整合包：SD 导入与独立风格

本包保留 FL～FL6、独立参数、五点曲线、拍后颗粒、正负光晕、正负暗角以及 JPEG L/M/S 支持，加入 SD 卡选文件导入、新增独立外观、确认删除和动态名称显示。公开版本仍是 v0.01，不单独发布内部事务版本。

## 机内使用

1. 把 `recipes/Portrait-grain-1.a7look` 复制到相机 SD 卡根目录。没有读卡器时，可使用相机「大容量存储」连接电脑复制，安全推出后拔 USB。
2. MENU → 拍摄设置 1 → 第 14 页，在与「创意外观」同级的「从 SD 卡导入」进入。用左右键选择文件，核对文件名，确认导入，再确认；看到独立的「完成」提示才算成功。
3. 进入「创意外观」，下拉列表末尾会新增「人像颗粒 1」。选定后也显示该名称。调节后执行保存→确认，看到完成。
4. 删除时先选中该自定义外观，到第 4 页选择「删除」，核对名称后确认。取消不会删除。内置 FL～FL6 不能删除，SD 卡上的配方文件也不会删除，之后可以重新导入。

文件名可自行修改，扩展名必须为 `.a7look`；内容必须符合 `A7FL-LOOK/1` JSON 格式，不能只改扩展名。每份新增配方包含稳定 ID、显示名称、基础 FL 和完整的 16 项参数，拥有独立保存记录，不覆盖原 FL。旧 `A7FL-PATCH/1` 参数覆盖文件不是新增风格格式，不应在此入口使用。运行时最多容纳 16 个自定义外观；填满上限尚未逐项实机验证。详细格式和开发记录见 `docs/look-recipes.md`。

示例使用 FL6 配色基础及颗粒 1，其他值明确写在文件中；它创建一个新风格，不修改内置 FL6。导入的是配方，不能据此导入新的图像算法或任意 LUT。

## 包内内容

- `a7fl.so`：已在开发机安装、完整回读的当前整合模块。
- `locales/`：从上一公开版六风格菜单资源生成当前菜单的中英文增量补丁。
- `tools/apply_release_locales.py`：离线生成菜单资源；`source/`：与清单提交一致的完整项目源码、构建和分阶段部署工具。
- `recipes/`：新增独立风格的测试配方；`docs/`：使用说明、历史验证和模拟色卡。
- `release-manifest.json`、`SHA256SUMS`：版本、源码提交和文件校验。

解压后运行 `shasum -a 256 -c SHA256SUMS`。重建菜单资源：

```sh
python3 tools/apply_release_locales.py \
  --baseline-dir /absolute/path/to/previous-v001-six-look-locales \
  --output-dir /absolute/path/to/new-custom-look-locales
```

生成器核对前像散列，只写本地新目录，不刷相机。当前中英文菜单 SHA-256 分别为 `abd89f064761b234623e603a461588f7433dbf1a282e669d413866ac26a7d33b` 和 `36bed3b1be93c6fc1ecea704ea487d4baec315543a599e7d01846e87b59feb42`。
